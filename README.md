# Standard Algorithm: Division

An interactive for the standard long division algorithm with 3- and 4-digit dividends and divisors from 5 to 50. Students write each quotient digit, multiply, subtract, and tap to bring down the next digit, repeating until every digit has been used. Check confirms an answer, Undo steps back, and Show me does the step the student is on: it fills in the quotient digit, product or difference, or brings the next digit down.

Open `index.html` in a browser, no build step needed.
